# Historical Baseline Feature Dictionary

The baseline represents election-history information available before adding news context. It is not a prediction model and it does not calculate vote redistribution, change, swing or incumbency.

| Feature | Group | Definition | Source | Derivation | Geographic requirement | Missing-value behaviour |
| --- | --- | --- | --- | --- | --- | --- |
| election_date | source | Published date of the target election event. | Completed official election event record. | Copied unchanged. | None. | Remain NULL if unavailable in the source record. |
| election_type | source | Configured type of the target election event. | Completed election configuration and event record. | Copied unchanged. | None. | Remain NULL; never inferred from a year. |
| number_of_candidates | deterministically_derived | Number of published candidate rows in the target ward. | Official target result-page candidate rows. | Count candidate rows for one target area ID. | None. | NULL when candidate rows are unavailable; never zero-filled. |
| number_of_parties_contesting | deterministically_derived | Number of distinct original published party labels in the target ward. | Official target result-page candidate rows. | Count distinct non-null original party labels only. | None. | NULL when candidate rows are unavailable. |
| number_of_seats | source | Official Seats value published for the target ward. | Official Voting Summary on the target result page. | Consensus of unchanged source values across candidate rows. | None. | Remain NULL; never derived from election year or winners. |
| candidate_competition_level | deterministically_derived | Single, two-candidate or multi-candidate contest indicator. | Official target candidate rows. | Classify only the published candidate-row count. | None. | NULL when the count is unavailable. |
| party_competition_level | deterministically_derived | Single, two-party or multi-party contest indicator. | Original official party labels in target candidate rows. | Classify only the distinct published-party count. | None. | NULL when party labels are unavailable. |
| turnout_available | source_availability | Whether an official turnout value is published for the target ward. | Official Voting Summary on the target result page. | True only where all source rows agree on one non-null value. | None. | False/NULL reports availability only and never substitutes a turnout. |
| electorate_available | source_availability | Whether an official electorate value is published for the target ward. | Official Voting Summary on the target result page. | True only where all source rows agree on one non-null value. | None. | Reports availability only; no electorate is substituted. |
| rejected_ballot_available | source_availability | Whether an official rejected-ballot value is published for the target ward. | Official Voting Summary on the target result page. | True only where all source rows agree on one non-null value. | None. | Reports availability only; no rejected-ballot total is substituted. |
| geographic_status | source_governance | Reviewed status of a historical-to-2026 geographic relationship. | Geographic Crosswalk Resolution Layer. | Read unchanged from reviewed mapping evidence using the documented status hierarchy. | Not applicable; this field documents the requirement. | Use unmapped when no reviewed relationship is present; never infer one by name. |
| historical_baseline_available | source_governance | Whether direct historical comparison fields may be used for a target ward. | Reviewed Geographic Crosswalk Resolution Layer. | True only for exactly one accepted_direct mapping with explicit previous-winner permission. | Exactly one accepted_direct mapping and previous_winner_allowed=true. | False for all blocked, ambiguous or unmapped relationships. |
| previous_election_event | direct_geographic_reference | Latest prior principal election for the approved directly matching historical area. | Official historical result data plus accepted_direct geographic evidence. | Select the latest earlier principal event for exactly the mapped historical area. | Exactly one accepted_direct mapping with explicit previous-winner permission. | NULL for partial, not comparable, requires-review or absent mappings. |
| previous_winning_party | direct_geographic_reference | Original published party label of one source-reported elected candidate in the prior event. | Official historical candidate outcome and party fields. | Expose only when exactly one source-reported elected candidate exists; no vote ranking is calculated. | Exactly one accepted_direct mapping with explicit previous-winner permission. | NULL if geography or winner evidence is not unambiguous. |
| previous_winning_candidate_vote_share | direct_geographic_reference | Published vote share of the source-reported elected candidate in the prior event. | Official historical candidate result row. | Copied from the selected elected candidate; no change or swing is calculated. | Exactly one accepted_direct mapping with explicit previous-winner permission. | Remain NULL when unavailable. |
| previous_turnout | direct_geographic_reference | Official turnout published for the latest earlier principal event in the mapped area. | Official historical Voting Summary. | Retain one shared source value across the earlier event's candidate rows. | Exactly one accepted_direct mapping with explicit previous-winner permission. | Remain NULL if the official source did not publish turnout. |
| previous_competitiveness | direct_geographic_reference | Candidate and party counts for the latest earlier principal event in the mapped area. | Official historical candidate rows. | Count published rows and exact original party labels; no vote ordering is calculated. | Exactly one accepted_direct mapping with explicit previous-winner permission. | Remain NULL if earlier candidate rows are unavailable. |
| party_previously_contested | direct_geographic_reference | Whether the exact original party label previously contested in the directly mapped historical area. | Official target and prior candidate party labels. | Compare exact labels across earlier principal events in one approved direct lineage. | Exactly one accepted_direct mapping with explicit previous-winner permission. | NULL rather than false where geography is unresolved. |
| candidate_appeared_in_previous_events | unavailable | Personal candidate continuity across events. | No explicit candidate identifier is present in completed source data. | No name-only matching is permitted. | A direct area mapping alone is insufficient without explicit identity evidence. | Always NULL/unresolved in this layer. |
| first_observed_appearance | direct_geographic_reference | Whether an exact original party label has no earlier recorded contest in the approved direct lineage. | Official target and earlier candidate party labels. | Compare exact original labels across earlier principal events only. | Exactly one accepted_direct mapping. | NULL rather than true/false where geography is unresolved. |
| party_vote_share_change | unavailable | Change in party vote share between elections. | Not generated in this layer. | Blocked to prevent unsupported comparison or redistribution. | Not applicable. | Always NULL/unavailable. |

`accepted_direct` is necessary but not sufficient for direct historical comparison: the reviewed row must also have `previous_winner_allowed=true`. `partial_crosswalk_available`, `not_comparable`, `requires_review`, and unpermitted direct rows remain visible as evidence but leave comparison features NULL. Candidate names are never used as identity keys; UK Independence Party and Reform UK are separate exact party labels.
