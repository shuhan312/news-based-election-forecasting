# Extraction prompt - version prompt-v1.1-2026-07-26

The canonical prompt text is generated by
`src/llm_extraction/pilot_sample.py::build_system_prompt()` (byte-
stable: no clocks, no run ids - reproducible and cache-friendly).
This document records what changed from prompt-v1.0 and why.

## Changes from v1.0, each tied to a measured pilot failure

### 1. Evidence quotation rule (hardened)

v1.0 said "copied VERBATIM". The pilot showed that is not explicit
enough: the model's dominant error (8 R1 rejections in 5 records)
was shortening long quotes with an ellipsis, plus occasional light
reconstruction. v1.1 spells out the failure modes:

> copied CHARACTER-FOR-CHARACTER ... NEVER shorten a quote with
> "..." or any ellipsis, NEVER splice two passages together, NEVER
> reconstruct a quotation from memory. If a passage is long, choose
> a SHORTER CONTIGUOUS span instead.

### 2. Offset rule (removed from the model's job)

v1.0 allowed optional char_start/char_end; the model got them wrong
once (R2). Character positions are not something an LLM should
count - the verbatim text IS the identifier, and offsets can be
recomputed deterministically downstream whenever needed. v1.1:

> Do NOT output char_start or char_end - the verbatim text is the
> identifier.

### 3. Leakage evidence rule (new)

One pilot record set contains_poll without support (R7). v1.1 adds
rule 6b: any contains_poll / contains_prediction /
contains_election_result flag requires BOTH a verbatim
leakage.evidence_span AND a leakage.explanation of why the content
risks contaminating pre-election analysis. Unsupported leakage
classification is forbidden.

### 4. Taxonomy pointer

The prompt now instructs `taxonomy_version: "issues-v1.2"` and
describes when `election_administration` applies (polling
arrangements, voting procedures, counting arrangements,
administration issues).

Everything else - the eleven-layer contract, the no-guessing rule,
the no-outcome-prediction rule, target-directed stance, Reform UK
consistency, honest confidence with review routing, metadata
copy-through, JSON-only output - is unchanged from v1.0.
